# 🗨️ WebSocket Chat App (Python + Docker)

A minimal real-time chat server built with **Python** and **WebSockets**, containerized using **Docker**. This is a learning-focused project intended to explore the fundamentals of socket-based communication, Dockerization, and eventually multi-language backends.

---

## 📦 Features

- Real-time messaging via WebSocket protocol
- Python-based WebSocket server
- Dockerized for easy deployment
- Frontend-agnostic (can be connected to any WebSocket-compatible client)

---

## 🧱 Tech Stack

- **Backend**: Python 3.13, `websockets`
- **Containerization**: Docker
- **Protocol**: WebSocket (`ws://`)
